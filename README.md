# Student Performance Prediction System 📊

A Machine Learning-powered web application that predicts student academic performance based on various educational and demographic factors. The system helps analyze student outcomes and provides data-driven insights for performance evaluation.

## Features

* Student Performance Prediction
* Machine Learning Model Integration
* Interactive Web Interface
* Real-Time Prediction Results
* Data Analysis and Visualization
* User-Friendly Dashboard

## Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* Python
* Flask

### Machine Learning

* Scikit-learn
* Pandas
* NumPy

### Visualization

* Matplotlib
* Seaborn

## Installation

1. Clone the repository

```bash
git clone https://github.com/Dakshjainpiet/Student-Performance-Prediction-System.git
```

2. Navigate to the project directory

```bash
cd Student-Performance-Prediction-System
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python application.py
```

5. Open your browser and visit:

```text
http://127.0.0.1:5000
```
